# Beacon Relay playtest downloads

[Find builds on GitHub Releases](https://github.com/MudDev/beacon-relay-downloads/releases).

| Platform | Download |
| --- | --- |
| Windows x86-64 | Run the `-windows-x86_64-setup.exe` installer. Playtest installers may prompt for Windows SmartScreen review. |
| macOS | Open the `-macos-universal.dmg` and drag the app into Applications. The preview is ad-hoc signed. |
| Android | Install the `-android.apk` on an ARM64 or x86-64 device. Android may ask for permission to install from your browser or file manager. |

Compare downloaded files against the release's `SHA256SUMS.txt`. Release notes list the build version and source commit.

In Beacon Relay, open **Online** to sign in or create an account. The playtest address is `https://game-test.techsonix.com:8443`.
